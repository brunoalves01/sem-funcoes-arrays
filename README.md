# 🚀 Exercícios de Lógica com Vetores (JavaScript Raiz)

Este repositório foi criado para armazenar as soluções de uma lista de exercícios focados na manipulação de vetores (arrays) em JavaScript. O grande desafio deste projeto foi desenvolver a lógica **sem utilizar funções nativas de array**  forçando o uso de estruturas de repetição e lógica.

---

## 📋 Tarefas Desenvolvidas

Abaixo estão os detalhes de cada um dos programas desenvolvidos:

### 1️⃣ Inversão de Nomes
* **Enunciado:** Um programa que lê 7 nomes de pessoas, guarda-os em um vetor e, ao final, mostra uma listagem com todos os nomes na ordem inversa daquela em que foram informados.
* **Foco:** Manipulação de índices de trás para frente.

### 2️⃣ Média e Valores Acima da Média
* **Enunciado:** Um programa que lê um vetor com 8 números reais, calcula a média dos valores armazenados e, em seguida, exibe apenas os valores que estão acima dessa média.
* **Foco:** Acumuladores, cálculo de média e estruturas condicionais dentro de loops.

### 3️⃣ Filtro de Menores de Idade
* **Enunciado:** Um programa que lê o nome e a idade de 9 pessoas e guarda esses valores em dois vetores estruturados (em posições relacionadas). No final, exibe uma listagem contendo apenas os dados das pessoas menores de idade.
* **Foco:** Vetores paralelos e validação de dados.

### 4️⃣ Interseção de Vetores (Sem Repetição)
* **Enunciado:** Lê dois vetores de 5 elementos inteiros cada e cria um terceiro vetor contendo apenas os elementos que estão em ambos (interseção), garantindo que não haja valores repetidos.
* **Exemplo:**
    * `Vetor 1` ➡️ `[1, 2, 3, 4, 5]`
    * `Vetor 2` ➡️ `[3, 4, 5, 6, 7]`
    * `Resultado` ➡️ `[3, 4, 5]`
